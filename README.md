## 📋 Problem Statement
Resumes are crucial for job applications, but most fail to create impact due to poor formatting, weak wording, or missing skills. This tool helps students and professionals optimize their resumes using AI.

## ✨ Features
- ✅ **PDF Resume Upload** - Upload any resume in PDF format
- ✅ **Skill Extraction** - Automatically identifies technical and soft skills
- ✅ **Resume Rating** - Get a score out of 10 based on impact and clarity
- ✅ **Professional Summary** - AI-generated 2-line summary
- ✅ **Job Description Matching** - Compare against target job requirements
- ✅ **Improvement Suggestions** - Actionable tips for each section
- ✅ **Re-evaluation** - Track score improvement to achieve 8/10+

## 🛠️ Tech Stack
- **Frontend & Backend**: Streamlit (Python)
- **PDF Parsing**: PyPDF2, pdfplumber
- **AI/ML**: OpenAI GPT-3.5, spaCy
- **Deployment**: Streamlit Cloud
